 # Calculadora de IMC ⚖️

## Sobre o Projeto

Este projeto apresenta uma Calculadora de Índice de Massa Corporal (IMC) desenvolvida com finalidade educacional. O objetivo principal não está apenas na realização do cálculo, mas também em utilizar a aplicação como uma forma prática de aprender sobre controle de versão. A atividade foi elaborada para demonstrar o funcionamento e a utilização do **Git** e do **GitHub** durante o processo de desenvolvimento de software.

## Tecnologias e Ferramentas

* **Linguagem de Programação:** Java
* **Ambiente de Desenvolvimento:** Visual Studio Code (VS Code)
* **Sistema de Controle de Versão:** Git

## Autoria e Contexto Acadêmico

Projeto desenvolvido por **Maria Luísa do Carmo Cardoso** como parte das atividades práticas do curso de Ciência da Computação do Centro Universitário Una - Barreiro. A atividade tem como foco o aprendizado de comandos pelo terminal, organização de repositórios e utilização de ferramentas de versionamento.
